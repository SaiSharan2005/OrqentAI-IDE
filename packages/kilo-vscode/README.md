# smartAI — AI Coding Agent, Copilot, and Autocomplete

An AI-powered coding assistant that generates code from natural language, automates tasks, and runs terminal commands — built for teams and enterprises.

## Features

- **Code Generation** — Generate code from natural language descriptions
- **Inline Autocomplete** — Intelligent code completions as you type
- **Task Automation** — Automate repetitive coding tasks
- **Automated Refactoring** — Refactor and improve existing code
- **Browser Automation** — Interact with web pages using AI
- **Terminal Commands** — Run and explain terminal commands
- **Multi Mode** — Plan with Architect, Code with Coder, Debug with Debugger, or create custom modes
- **MCP Server Support** — Extend agent capabilities with MCP servers
- **500+ AI Models** — Claude, Gemini, GPT, Grok, Codex, Llama, Mistral, and more

## Get Started

1. Install the smartAI extension from the VS Code Marketplace
2. Sign in with your smartAI account
3. Select a project and start coding with AI

## How It Works

smartAI connects to your organization's SmartAI platform, giving your team:

- **Centralized billing and usage tracking** per developer
- **Project-level AI configurations** — agents, rules, workflows, and MCP servers
- **Role-based access control** — manage who can use what
- **AI proxy** — route all AI requests through your organization's gateway
